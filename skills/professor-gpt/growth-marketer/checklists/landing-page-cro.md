# Landing Page CRO Checklist

Run top to bottom before launch and during any conversion audit. Fix items in order — message problems dwarf layout problems.

## 1. Message & Positioning (highest leverage)
- [ ] Headline states the outcome for the visitor, not the product's feature ("Close books in 3 days, not 3 weeks" vs "AI-powered accounting platform")
- [ ] Headline matches the ad copy / search query that brought the visitor (message match)
- [ ] Subhead answers "how" in one sentence
- [ ] A stranger can answer in 5 seconds: What is it? Who is it for? Why should I care?
- [ ] Copy addresses the visitor's stage of awareness (cold traffic needs problem framing; retargeting can go straight to offer)
- [ ] Jargon test: would a smart outsider understand every word above the fold?

## 2. Call to Action
- [ ] One primary CTA per page, repeated after each major section
- [ ] CTA copy is a specific verb + value ("Start free 14-day trial"), never "Submit" or "Learn more"
- [ ] Friction reducers adjacent to CTA ("No credit card required · Cancel anytime · Setup in 5 min")
- [ ] Campaign pages: main navigation removed (every nav link is an exit)
- [ ] Secondary CTA (demo, video) visually subordinate to primary

## 3. Trust & Social Proof
- [ ] Proof is specific and quantified ("Cut CAC 31% at Acme" beats a wall of logos)
- [ ] Testimonials include full name, title, company, photo — anonymous quotes are counterproductive
- [ ] Logos/badges relevant to the target segment (enterprise buyers want SOC 2; SMBs want G2 stars)
- [ ] Risk reversal stated: guarantee, free tier, or easy cancellation

## 4. Form & Friction
- [ ] Form fields ≤ 4 for top-of-funnel (every extra field costs roughly 5-10% completion)
- [ ] Only ask for what sales/marketing will actually use this week
- [ ] Inline validation; errors preserve entered data
- [ ] Multi-step form for >5 fields (start with the easy commitment)
- [ ] Autofill and correct input types work on mobile (email keyboard, etc.)

## 5. Structure & Readability
- [ ] F-pattern respected: key info left-aligned, scannable subheads every 2-3 paragraphs
- [ ] Sections follow objection order: outcome → how it works → proof → pricing/objections → final CTA
- [ ] Hero image shows the product or outcome, not stock-photo handshakes
- [ ] Page passes the squint test: primary CTA is the most visually prominent element

## 6. Technical & Speed
- [ ] LCP < 2.5s on 4G mobile (test with PageSpeed Insights, not office wifi)
- [ ] CLS < 0.1 — no layout jumps as images/fonts load
- [ ] Images compressed and lazy-loaded below the fold
- [ ] Page renders correctly at 360px width; CTA reachable without horizontal scroll
- [ ] Analytics events on CTA click, form start, form submit, scroll depth 50/90%

## 7. Post-launch
- [ ] Session recordings reviewed after first 200 visits — watch 10, note rage-clicks and scroll stalls
- [ ] Scroll map checked: if <50% reach the second CTA, restructure
- [ ] A/B test queue seeded: headline first, then hero, then CTA copy (in impact order)
